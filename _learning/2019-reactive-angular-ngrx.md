## About the course

A workshop-format course that takes an existing Angular application and refactors it
onto NgRx step by step. Working against real code means the trade-offs land harder than
a from-scratch demo would — you see the boilerplate cost as well as the payoff.

## What it covers

**Reactive foundations**

- RxJS observables, operators and composition
- Thinking in streams rather than imperative state updates
- The problems with service-held state as an application grows

**NgRx building blocks**

- Store, and the one-way data flow it enforces
- Actions as the single vocabulary for change
- Reducers for pure, predictable transitions
- Selectors for derived and memoised reads

**Side effects**

- Effects for async work and API calls
- Keeping components free of orchestration logic

**Tooling**

- Redux DevTools for time-travel debugging
- Structuring a feature-based store

## Follow-along repo
