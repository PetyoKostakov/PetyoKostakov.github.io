# AWS for Developers

Learn how to build scalable, reliable applications on Amazon Web Services.

## Course Overview

This intermediate course teaches developers how to architect and deploy applications on AWS. You'll go from understanding basic AWS services to deploying production-ready applications.

## What You'll Learn

### Module 1: AWS Fundamentals
- AWS Console and CLI
- Regions and Availability Zones
- IAM and Access Management
- AWS Well-Architected Framework

### Module 2: Compute Services
- EC2 instances
- Auto Scaling Groups
- Load Balancers
- Application Load Balancer (ALB)

### Module 3: Storage Solutions
- S3 buckets and objects
- CloudFront CDN
- EBS volumes
- Glacier for archival

### Module 4: Database Services
- RDS (PostgreSQL, MySQL)
- DynamoDB for NoSQL
- Caching with ElastiCache
- Database migration strategies

### Module 5: Serverless Architecture
- Lambda functions
- API Gateway
- Serverless web applications
- Cost optimization

### Module 6: Security & Monitoring
- Security groups and NACLs
- CloudWatch and logging
- X-Ray for tracing
- Securing sensitive data

## Prerequisites

- Basic understanding of web applications
- Familiarity with Linux/Unix command line
- Programming experience (any language)
- AWS account (free tier available)
