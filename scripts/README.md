# 🔧 Utility Scripts

Helper scripts for your Jekyll portfolio.

---

## Available Scripts

### verify_setup.sh
Verifies your Jekyll setup is correctly configured.

**Run:**
```bash
bash verify_setup.sh
```

**Checks:**
- ✅ Ruby version (3.4.0+)
- ✅ Gemfile exists and has required gems
- ✅ Bundler is installed
- ✅ Jekyll can load
- ✅ Configuration files present

**Output:**
```
🔍 JEKYLL PORTFOLIO SETUP VERIFICATION
...
✅ VERIFICATION COMPLETE
```

---

## How to Use

All scripts should be run from the root directory:

```bash
cd /Users/kostapet/git/PetyoKostakov.github.io
bash scripts/verify_setup.sh
```
