## ✍️ CREATE NEW CONTENT

### Create a Blog Post
1. Create file: `_posts/2024-09-10-my-title.md`
2. Copy template:
```markdown
---
layout: post
title: "Your Title"
date: 2024-09-10 10:00:00 +0000
categories: [blog, category]
tags: [tag1, tag2]
---

Your content here...
```

### Create a Course
1. Create file: `_courses/course-name.md`
2. Copy template:
```markdown
---
layout: page
title: "Course Title"
description: "Short description"
level: "Beginner"
topics:
  - Topic 1
  - Topic 2
  - Topic 3
permalink: /courses/course-url/
---

Course content here...
```

## 💻 USEFUL COMMANDS

```bash
# Install dependencies
bundle install

# Run development server
bundle exec jekyll serve

# Run on different port
bundle exec jekyll serve --port 4001

# Build for production
JEKYLL_ENV=production bundle exec jekyll build

# Clean build files
bundle exec jekyll clean

# Update dependencies
bundle update
```
